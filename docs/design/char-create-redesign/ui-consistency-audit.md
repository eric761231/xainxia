# 全介面美術、尺寸與版面一致性檢查

日期：2026-09-18。結論：目前僅部分共用，尚未全專案一致。新版男女創角圖仍是概念提案，並未套入正式介面。

本輪查核全部 13 個 `lib/ui/screens` 畫面檔、共用面板／訊息框、主題、XML／XAML 配置及地圖編輯器。依實際 Dart 使用方式核對，沒有把未被使用的 XML 座標當成現況。本輪是程式與配置審查，沒有重新連線逐頁截圖；下列尺寸風險不是已重現的視覺故障。

## 已確認的共通差異

1. **樣式來源分散**：`theme.xaml`、`GameUiStyles`、`PanelTheme` 與創角／選角 XML 各自定義色票、字級與間距。改一份不會同步全站。
2. **字型較統一，字級與描邊不統一**：主要遊戲頁多使用 `GameUiFonts.kingHwaOldSong`，但登入描邊、一般雙向陰影、面板單陰影並存；不能將陰影視為完全相同的黑描邊。
3. **相同基準解析度不等於相同尺寸**：登入按邏輯像素配置，創角／選角整體縮放，HUD 又有 boost。1280×720 時 HUD 的 12px 文字若在 boost 區域，依公式約為 8.8px；这是計算風險，尚未在本輪逐頁目視驗證。
4. **點擊區有落差**：共用分頁高 30、關閉圖示 GestureDetector 僅包 16px 圖示，未明示 44px 最小熱區；與新計畫的最小操作區不符。
5. **版面沒有共用安全邊距與斷點**：部分為固定寬高、部分比例 clamp、部分 Transform 縮放。拖曳面板只累加 offset，`TabbedPanel` 本身未限制可視邊界。
6. **兩張新預覽本身也不是統一規格**：男女圖的山景、圖示、分隔線及底部不同。正式版必須只保留一個背景／元件系統；男性預覽灰色底帶不採用。

## 建議統一規範（提案，未修改程式）

- 美術主色：白玉、青玉、淡金；主要文字亮白＋真正黑描邊，選中以金色／青玉並搭配形狀提示。危險操作保留紅色語意。
- 前置流程：登入、選服、創角、選角共用透明容器、主次按鈕、字體、背景處理與返回位置。取消整片黑筆刷底與包圍式框線。
- 遊戲內：沿用同一字型、色票和圖示筆觸，但另外制定緊湊 HUD／資訊面板規格。深色底是否保留局部支撐可讀性，應先以實景預覽決定；既有使用者透明要求針對前置 UI，不據此擅自移除所有遊戲面板底色。
- 建議最終顯示字級：頁標題 28–36、區塊標題 22–24、正文 16–18、次要資訊至少 14 邏輯 px。不能再隨整頁等比縮小到 9px。
- 間距採 4/8/12/16/24/32，共用控制項高度 48、主操作 52–56；圖示視覺可小，點擊區至少 44×44。所有數字為提案，不是已通過的實測值。
- 1920×1080 為美術基準；1280×720、1920×929、窄窗另定重排。背景 cover、立繪 contain；文字與熱區有下限。資訊面板允許捲動，拖曳後仍能關閉。

## 後續實作與驗收順序

1. 先定共用色票／字級／按鈕與背景，修正兩張創角預覽差異，再同步做創角與選角。
2. 對齊登入／選服、載入／過場及所有訊息框，清理失效或被覆寫的 XML 設定。
3. 另製 HUD＋背包／社交／修練實景預覽，決定可讀性用底色與尺寸，之後才改遊戲內主題。
4. 各頁驗收正常、hover、pressed、disabled、錯誤、長文字與空狀態；三個桌面尺寸及窄窗均截圖。需服務資料的頁面使用可重現 fixture，再補實際遊戲驗證。
