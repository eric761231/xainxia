# 創角男女立繪與介面重繪計畫

日期：2026-09-18。階段：設計提案與預覽，尚未替換遊戲素材或修改正式介面。

其他畫面的一致性檢查見 [全介面審查](ui-consistency-audit.md)。目前尚未一致；正式創角實作需先收斂共用規範，並同步處理選角。

## 設計方向

使用者仍看到不理想的女性角色，因此本次採全新立繪與重新配置創角元件。預覽見 [preview-v1.png](preview-v1.png)。這是整體美術概念圖，不是程式執行截圖，也不是已驗證透明通道的可直接上線素材。

女性以白玉、青綠與銀飾為主，重新繪製臉部、髮型、姿勢及衣服層次。保留仙俠全身立繪方向，身體、主衣料與頭髮實心區域不透出背景；薄紗只在外側少量使用。正式素材不包含山景、平台、文字或按鈕。

介面採透明底、亮白字與黑描邊，選中項目用金色與青玉色。移除原有大面積黑色筆刷底與包圍式容器框線，裝飾限小型金線與圖示。背景細節與亮度需讓位給文字，避免用降低整個介面透明度來處理。

## 版面與互動

以 1920×1080 為設計基準，採左、中、右三區與獨立底部操作區，保留至少 48px 安全邊距。

| 區域 | 配置 | 行為 |
| --- | --- | --- |
| 左上 | 返回 | 保留既有返回流程 |
| 左側約 24% 寬 | 八種靈根，兩欄四列；下方顯示選中名稱及描述 | 整個圖示與文字均可點選；選中外圈與文字同步提示 |
| 中央約 48% 寬 | 全新女性與全新男性立繪 | 完整頭飾與雙腳，等比例 contain；不覆蓋側欄點擊區 |
| 右側約 28% 寬 | 神識、體魄、敏捷、悟性四列；剩餘點數與重置紧接下方 | 標籤、減號、數值、加號各自對齊；保留既有分配規則 |
| 底部中央 | 性別切換與修士名號 | 獨立配置區，預留約 140px；立繪底端停在此區上緣，避免預覽中的裙襬遮擋 |
| 右下 | 進入遊戲 | 與名號區對齊；保留必填、送出、錯誤及防重複送出行為 |

一般元件間距採 12–20px，區塊間距 24–32px；點擊範圍至少 44×44px。1280×720 與 1920×929 必須另做排版驗收，窄螢幕改為可捲動配置，不能只縮小整張 UI 使文字不可讀。

預覽中的字體、裝飾字與圖示為生成示意。正式版所有可操作文字由 Flutter 繪製，使用專案繁中字型與白字黑描邊，不把整張預覽直接當 UI。右側背景多出的裝飾文字不納入正式素材。

## 執行順序

### 男性補充範圍

男性同樣全部重繪，不沿用現有男性圖。預覽見 [preview-male-v1.png](preview-male-v1.png)：成年男性修士、新臉型與束髮、銀玉冠、白青層疊長袍、較俐落肩線與腰封、佩劍及完整靴子。與女性共用色彩、光源方向、畫面比例、腳底定位與 UI；切換性別只更換立繪及選中狀態，不改山景或元件位置。

兩張生成預覽的背景、圖示和裝飾存在差異，僅供造型與配置參考。正式版採同一背景與同一套元件。男性預覽底部出現的灰色橫帶及輸入底色不採用，依透明底需求實作。男女均須獨立輸出真正透明 PNG，使用相同 Alpha、裁切與 Web 發布驗收；以下女性製作流程也完整套用於男性，兩者一起交付。男性提示詞見 [prompt-male.txt](prompt-male.txt)。

1. 以此預覽確認女性造型、兩欄靈根及底部操作區方向，再進入正式替換。
2. 單獨生成新版女性全身 PNG，要求真正透明背景。檢測 Alpha 與 RGB，拒收畫入的棋盤格、人體破洞或整體半透明；保留原檔備份與新版本名稱。
3. 將立繪放到黑、白、灰及實際山景背景比較。臉、頭髮內部、手臂與衣服主體應實心，邊緣保留抗鋸齒；頭飾和腳不能裁切。選角共用同一新版女性素材。
4. 調整 `char_create_layout.xml` 與 `lib/ui/layout/char_create/` 尺寸配置，將左側靈根改為兩欄。修改 `lib/ui/widgets/char_create/` 的靈根、屬性列、性別、名號與開始按鈕，沿用既有資料與事件。
5. 以程式繪製文字、選中圈、分隔線與互動狀態；需要獨立美術的圖示另行輸出，不從含文字的整張概念圖直接切成按鈕。
6. 使用內容雜湊發布新版素材，更新 `char_create_ui_assets.dart`、預載及打包引用。重建正式 Web，核對使用者實際網址的 HTTP 圖片內容與版本。
7. 驗收創角男女切換、八種靈根、點數加減／歸零／重置、姓名輸入、進入遊戲與返回。檢查選角共用立繪及登入既有透明介面沒有回歸。

## 驗收標準與交付

- 必须是新女性造型；不能只是舊圖調整透明度。
- 身體與主要衣服不能透出山景，沒有棋盤底、黑白邊、頭髮破洞。
- 三個桌面尺寸均無元件重疊、文字截斷、裙襬遮住输入區；按鈕可用。
- 視覺文字清楚，無灰黑大容器、無包圍式外框。
- 提供正式瀏覽器的新舊對照截圖、測試結果、發布雜湊與實際入口。
- 本輪交付為本計畫及整體預覽；獨立透明立繪、程式與上線驗收屬後續實作，不宣稱已完成。
