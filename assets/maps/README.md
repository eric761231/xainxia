# 地圖底圖

## 檔名慣例

`{mapId}.png` —— 檔名就是伺服器 `map` 表的 `map_id`。
例：`0.png` = 修練洞府、`1.png` = 黑森林。

放進來就會被自動載入，不需要註冊或改程式
（`SceneAssetLoader.loadMapBackground` + `IsoMapComponent.applyBackground`）。
沒有對應圖檔的地圖會退回純灰格網，不會報錯。

## 尺寸規格

**一律 1280×1280 正方形**，但**可以更大** —— 見下面「比 1280 大的底圖」。

| 項目 | 數值 |
|---|---|
| 格數 | 20 × 20 |
| 單格 tile | 64 × 32（等距 2:1） |
| 等距菱形 | 1280 × 640 |
| 正方底圖 | 1280 × 1280 |
| 上下留白 | 各 320（= 邊長 ÷ 4） |

菱形只佔正方形中間的一半高度，上下兩塊三角區是「補角」裝飾，
**走不進去**（可走區是 1..20 的菱形）。

換算：`正方底圖邊長 = 格數 × 64`，`留白 = 邊長 ÷ 4`。
等距投影恆為 2:1，所以留白比例固定。

## 對齊方式

底圖對齊的是**可走區（1..20）的菱形中心**，不是整張陣列中心
—— 陣列外圍還有一圈索引 0 的不可走邊界，照陣列置中會往上偏半格（16px）。

進遊戲時 log 會印出實際對齊結果，可用來核對美術：

```
底圖 assets/maps/1.png 1280x1280 已對齊可走區中心 | 可走 1..20（20 格，tile 64x32）
→ 菱形 1280x640 | 建議底圖尺寸 1280x1280（上下各留白 320）
```

## 覆寫（選用）

若某張地圖要改用 `assets/sences/` 底下的圖，在 `map` 表設 `gfxid`
為 `assets/data/object_catalog.json` 的物件 id（與 `property.pngid` 同一套編號），
會優先於 `{mapId}.png`。`gfxid = 0` 即走檔名慣例。


## 比 1280 大的底圖也可以，不用改程式

`IsoMapComponent.backgroundOrigin()` 回傳 `(centerX − bgW/2, centerY − bgH/2)`
—— 底圖是**依自己的尺寸**置中對齊可走區菱形的，所以加寬只是四周多留白，
對齊完全不受影響。

`0.png`（中式院牆）就是 **1344×1344**：原畫的銅柱頭與石基座往外伸出
22~23px，1280 放不下，只能在「切掉」與「牆體縮短」之間二選一。多留 32px
的邊就兩個都不必犧牲。

由 DrawPng 產生的底圖天生對齊，`map_backgrounds.json` 的 offset 一律留 0。
